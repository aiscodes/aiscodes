### What I work on

**Frontend** — React 18, Next.js (App Router, React Server Components, SSR), TanStack Router and Query, Zustand, Redux. Design systems: 60+ TypeScript components on Radix UI and Tailwind, documented in Storybook.

**Mobile** — React Native and Expo for iOS and Android, from architecture through App Store and Google Play releases.

**Backend where it's needed** — Node.js (Express, Nest), REST and GraphQL, PostgreSQL, MongoDB, Prisma.

**Quality as part of the build** — Playwright, Jest and React Testing Library; WCAG 2.1 AA accessibility; CI/CD on GitHub Actions with linting and dead-code detection wired into the pipeline.
