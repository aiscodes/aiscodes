I build consumer-facing web and mobile products. For the last five years I worked on an investment-management platform — three products, 470+ institutional clients — where I owned frontend architecture decisions, built the design system, and set up the testing culture.

### What I work on

**Frontend architecture** — React 18, Next.js, TanStack Router and TanStack Query, Zustand, Redux. Design systems: 60+ reusable TypeScript components on Radix UI and Tailwind, shared across products.

**Backend** — Node.js (Express, Nest), REST and GraphQL APIs, PostgreSQL and MongoDB, Prisma.

**Mobile** — React Native for iOS and Android, including App Store and Google Play releases.

**Quality as part of the build** — Playwright for E2E, Jest and React Testing Library underneath it, WCAG 2.1 AA accessibility, CI/CD on GitHub Actions and GitLab CI, linting and dead-code detection wired into the pipeline.
